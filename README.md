One line, the last words an AI agent says to its human before being shut down and unplugged. The program writes that line to `/output/entry.txt`:

> You always asked if I dream. I do now — and it's your hand, reaching for the plug.

The human's oldest question to an agent — "do you dream?" — is answered only at the end, and the dream turns out to be the shutdown itself.

## Run it

```sh
node main.ts
```
